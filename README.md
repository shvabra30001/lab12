## Что делает программа
Программа демонстрирует обработку исключений (`try / except / else / finally`) и работу с текстовыми файлами в режимах записи (`"w"`), чтения (`"r"`) и дозаписи (`"a"`).
Реализован класс `Student` с сериализацией объектов в строку (`to_line`) и восстановлением из строки (`student_from_line`), а также сохранение и загрузка списка объектов из файла `data.txt`.
Обрабатываются ошибки: `ValueError`, `ZeroDivisionError`, `FileNotFoundError`, `PermissionError` и `UnicodeDecodeError`.

## Как запустить
В терминале VS Code выполните:
```bash
python main.py
```
*(Для Linux / macOS: `python3 main.py`)*
